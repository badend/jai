# JAI — 제이에이아이 유한회사

제이에이아이 유한회사(JAI LLC)의 정적 소개 사이트입니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 단일 페이지 마크업 (히어로 · 사업영역 · 회사소개 · 접근방식 · 문의 · 푸터) |
| `styles.css` | 전체 스타일 (토큰 기반, 반응형, `prefers-reduced-motion` 대응) |

빌드 도구가 필요 없습니다. `index.html`을 브라우저로 열면 그대로 동작하며,
별도 스크립트·패키지·서버가 없습니다. 경로는 모두 상대 경로이므로
GitHub Pages 루트(`/`)와 로컬 파일 열기 양쪽에서 동일하게 표시됩니다.

## 배포

GitHub Pages — `main` 브랜치 `/` (root) 기준.

- 저장소: https://github.com/badend/jai
- 사이트: https://badend.github.io/jai/

## 수정 시

- 회사 정보(사명, 사업영역 문구)는 `index.html`의 해당 섹션에서 직접 수정합니다.
- 색·타이포·간격은 `styles.css` 상단 `:root` 토큰에서 조정합니다.
- 주소·전화·이메일 등 확인되지 않은 정보는 넣지 않았습니다. 확정된 값이 생기면
  `#contact` 섹션과 푸터에 추가합니다.
